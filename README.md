# Ronin RPG — El Sauce y la Ceniza

RPG narrativo 2D para Godot 4, ambientado en la provincia ficticia de Kanegawa en 1573. La primera base incluye una escena de prototipo con movimiento, diálogo con O-Ren, Honor y una interacción inicial con el pozo.

## Estado actual
- Proyecto Godot 4 creado en `game/`.
- Movimiento con flechas/WASD, diálogo inicial y Honor.
- Datos narrativos JSON para mundo, personajes, arco y misiones.
- **APK todavía no generado ni verificado.** El acceso de edición al repositorio no incluye por sí mismo un entorno Godot/Android SDK para compilar y probar un APK.

## Ejecutar
1. Instala Godot 4.x.
2. Abre `game/project.godot`.
3. Ejecuta el proyecto con F5.

Controles: WASD o flechas para moverse; Espacio/Enter para avanzar diálogo; E para interactuar.
